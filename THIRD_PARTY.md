# Third-party components

What Track Kommander bundles, and under which terms. Full licence texts ship
in `licenses/`; the app lists them under Settings ▸ About.

Last verified: 2026-09-23.

## Summary

Track Kommander itself is proprietary: free to use, distributed as binaries
only (`LICENSE`). Everything it bundles is permissive or LGPL, so nothing
bundled requires the app's source to be published; the LGPL obligations are
met as described below.

The LGPL components — Qt (via PySide6), FFmpeg (via PyAV), libsndfile (via
soundfile) and soxr — ship as separate shared libraries that can be replaced.
Do not link them statically.

Before adding a dependency, check its licence and the licences of any native
libraries its wheels bundle.

## FFmpeg

The PyPI `av` wheels bundle GPL codecs (x264, x265), so macOS and Windows use
the wheels in `vendor/wheels/`, built by `scripts/build_ffmpeg_lgpl.sh` /
`.bat`: an audio-only FFmpeg 8.0.1, LGPL-2.1-or-later, with no external
libraries.

Its source ships inside the app in `licenses/source/`: the unmodified
`ffmpeg-8.0.1.tar.xz` (from `vendor/source/`) and the build scripts.

## SQLCipher

`core/onelibrary.py` writes the OneLibrary database (`exportLibrary.db`) the
2023+ AlphaTheta players require. It is a SQLite file encrypted with SQLCipher,
so the app bundles `sqlcipher3-wheels`: the `sqlcipher3` Python binding (zlib
licence) with SQLCipher and OpenSSL 3 compiled in. Neither is LGPL, so the
static link is fine; their notices are in `THIRD_PARTY_NOTICES.txt` and
Settings ▸ About.

The schema and the fixed browse-menu rows are reproduced from the MIT-licensed
[onelibrary](https://github.com/v1vendi/onelibrary) project's capture of a
rekordbox 7 export. The passphrase the database is keyed with is the one every
rekordbox installation uses; it is a published constant, not a per-user or
per-licence secret, and the file holds only the user's own track metadata.

## Models

Only the CLAP model (`laion/clap-htsat-fused`, Apache-2.0) is bundled.

The optional embedding backends and `core/models.py` are off by default and
never shipped. Several of those models (Discogs-EffNet, the Essentia
classifiers) are CC BY-NC-SA 4.0 — **non-commercial**. Check a model's
licence before enabling or shipping it.
